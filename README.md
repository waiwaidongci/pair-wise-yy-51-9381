# 铁路危险货物运输路径审批与风险复核平台

源提示词编号：8。包含危险货物运输单编组、候选路径生成、MapLibre 路网风险叠加、Turf 里程测算、安全/运营/应急逐区段会签、替代方案与审计基线。

## 技术栈

Angular、Angular Material、NgRx、Angular Router、HttpClient、RxJS、MapLibre GL、Turf.js、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62051

```bash
npm run build
```

## 快照与协同机制

- **同一份快照**：运输单编组、区段限值（最大编组容量）、会签全部挂在 NgRx 单快照上，每次变更整体替换核心数据，版本号 +1。
- **逐段余量与排队**：运输单按当前编组逐段计算余量（限值 − 编组辆数），超容量区段自动进入排队，见工作台「区段通行余量 / 排队运输单」。
- **会签失效**：限值或编组一变，相关会签立即置为「已失效」并记录原因，须「重新确认」后才回到待确认。
- **并发先到者生效**：区段限值按版本号登记；两名调度同时修改同一区段时先到者生效，后到者操作记为「未生效」，草稿与冲突原因保留在登记席。
- **按操作号恢复**：每次提交按操作号（OP-N）留存完整快照并整体落盘；写入失败即回滚到失败操作号之前的完整快照，不会出现半份快照。工作台「演练：模拟下次写入失败」可现场验证。
- **待复核一致**：工作台、风险地图、审批页共用同一个 `selectPendingReview` 选择器与待复核条组件，三处显示必然一致。
